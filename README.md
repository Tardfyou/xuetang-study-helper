# 学堂在线学习助手

一个可手动安装到 Google Chrome 的轻量扩展，支持视频连播、自动 2 倍速、自动静音和当前作业题目提取。无需 API Key，无需构建或安装依赖。

## 功能

- 视频自然结束后，按照当前课程目录切换到下一个视频，跳过作业节点。
- 默认开启 **自动 2 倍速** 和 **自动静音**；新视频加载后继续应用。
- 使用播放器原生倍速、音量控件，避免设置被播放器重置；面板显示实际状态。
- 支持停止、手动暂停，以及指定页面上的下一节按钮。
- 读取当前作业题干、选项和平台实际返回的答案或解析字段。没有返回答案时明确提示，不调用 AI，不自动作答或提交。

## Chrome 手动安装

1. 在本仓库页面点击绿色 **Code** 按钮，再点击 **Download ZIP**。
2. 解压下载的 ZIP，得到 `xuetang-study-helper-main` 文件夹。请把文件夹保存在固定位置，安装后不要删除或移动。
3. 在 Chrome 地址栏输入 `chrome://extensions/` 并回车。
4. 打开右上角的 **开发者模式**。
5. 点击左上角 **加载已解压的扩展程序**。
6. 选择解压后直接包含 `manifest.json`、`content.js`、`README.md` 的文件夹，然后确认。**不要选择 ZIP 文件，也不要选择它的上层文件夹。**
7. 确认扩展列表中出现「学堂在线学习助手」且处于启用状态。
8. 打开或刷新学堂在线课程页；右下角应出现助手面板。

不需要开启「允许 Apple 事件中的 JavaScript」，也不需要安装油猴。

## 使用

### 连续播放

在具体视频页点击 **开始连续播放**。默认应用 2 倍速和静音，视频自然结束后自动进入目录中的后续视频。取消相应复选框可恢复 1 倍速或声音。

保持课程标签页打开。点击 **停止** 会暂停视频并停止自动切换；手动暂停视频后，助手不会自行强制恢复播放。浏览器若阻止首次播放，请手动点击播放器的播放按钮。

如果目录结构不兼容，可以点击 **指定“下一节”按钮**，再点击页面上的下一节按钮；这次点击只用于选取，不会跳转。按 Esc 可取消。

### 题目与平台解析

在具体作业页点击 **读取本题数据**，再按需要点击 **复制题目**。也可先选中页面文字，再点击 **提取选中文字**。

只有平台已返回的答案或解析字段才能显示；显示开关和“有解析”标记不代表已经返回答案。所有答案需要自行核对，作答和提交由你在原页面完成。图片题请结合原页面查看。

## 更新和卸载

- **更新：** 下载并解压新版，将文件覆盖到原安装文件夹；在 `chrome://extensions/` 中点击该扩展卡片上的重新加载按钮，再刷新课程页。
- **临时停用：** 关闭扩展卡片的启用开关，再刷新课程页。
- **卸载：** 点击扩展卡片上的「移除」，然后刷新课程页。

## 常见问题

- **看不到面板：** 确认扩展已启用，并刷新 `https://www.xuetangx.com/` 下的课程页。
- **没有切到下一节：** 检查助手是否已开始、自动切换是否勾选，以及当前目录是否还有后续视频。已到末尾时不会重新循环。
- **视频暂停：** 检查页面提示、浏览器自动播放限制和平台自身行为。助手不会强制恢复手动或平台触发的暂停。
- **页面刷新后不继续：** 刷新或完整页面跳转后需重新点击开始；课程页内切换会保留运行状态。
- **没有答案：** 说明本次题目响应没有返回答案，插件不会通过提交题目来试探答案。

## 兼容范围与数据

### 实测记录（2026-09-21，v0.1.1）

- 真实课程视频自然播放到结尾，捕获到 `ended` 事件，随后自动进入目录中的下一视频。
- 跳转后新视频持续播放，实际 `playbackRate=2`、音量为 `0`。
- 首节连续播放的一段测量中，约 151 秒实际时间推进约 302 秒视频内容，符合 2 倍速。
- 取消倍速和静音开关后，原生播放器恢复 1 倍速和原音量；重新勾选后恢复 2 倍速及静音。
- 本地隔离测试覆盖跳过作业、重复结束事件只切换一次、停止后不切换、不触发提交。
- 本次作业读取测试中，平台只返回题干及选项，没有返回正确答案或解析正文；助手如实显示未返回状态。

验证范围为当前课程的一次真实跨节切换，不代表已遍历所有课程或整门课程。

适配当前学堂在线网页课程目录和 HTML5 播放器。跨域嵌入播放器、不完整的懒加载目录或站点改版可能需要进一步适配。播放进度和成绩以平台实际记录为准。

扩展仅在 `https://www.xuetangx.com/*` 和 `https://xuetangx.com/*` 上运行，没有额外浏览器权限；不向外部服务上传课程数据。点击读取题目时，只使用当前登录会话 GET 页面已经请求过的题目接口。

开发参考：[Chrome Content scripts 文档](https://developer.chrome.com/docs/extensions/develop/concepts/content-scripts)。
